# 更新日志 · 不眠手记 / VIGIL 重构版

## v1.1.0 · 铅字旧梦 — 2026-11-13

### 全站视觉重制
- 采用深墨棕侧栏、泛黄文书纸、朱砂印记、灰绿机械漆与黄铜边线。
- 以近代打字机 / 中式老刊印为意象，重制首页 CSS 打字机、纸页、信笺边框、日期档案卡片。
- 写作页改为带朱线边距的手稿纸，阅读页改为正式文牍，档案管理页改为档案柜式信息层级。
- 新增本地提供的 `titlefont.ttf`、`textfont.ttf` 字体引用和系统字体降级方案。
- 新增纸张颗粒素材，兼容低动态效果与手机端四栏导航。

### 数据安全与写作
- 新增 `src/storage/drafts.js`：650ms 防抖草稿暂存、回到草稿续写、单篇舍弃、容量与损坏防护。
- 新增 `src/storage/backups.js`：自动本地备份、最多保留 5 份、手动创建、恢复、删除。
- 删除、导入、历史恢复前先尝试创建安全副本；失败即中止破坏性操作。
- 自动备份与草稿存储彼此独立，正式保存后仅清理当前草稿。
- 更新数据管理页，提供备份列表、字数、时间、手动备份和草稿列表。
- 进一步强化未保存草稿离开提示及备份异常反馈。

### 工程质量
- 保持原生 ES Modules 和独立 CSS，未改回单 HTML。
- 增补草稿与备份仓库自动化测试，覆盖异常和容量限制。
- 保留上一版原型的数据读取迁移，并保持原始 Key 不删除。
- 浏览器回归验证了首页、索引、写作、阅读和数据管理页面的主要流程。

### 兼容边界
- 不代表可直接读取完整旧项目 v2.8.2 的加密存储、旧数据库或服务端入口。
- 下载包不重新附带用户提供的字体二进制文件，需参照 `fonts/README.md` 还原。
