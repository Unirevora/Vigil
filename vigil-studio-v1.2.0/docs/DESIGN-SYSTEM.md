# 不眠手记 v1.2 · 设计系统

## 定位

干净、安静、具有近代纸张与中式印刷气息的手记工具，而不是装饰繁复的民国主题展板。

视觉原则：

- **信息先于装饰**：标题、正文、日期和操作为首要层级。
- **用留白构建秩序**：页面最多两个主要焦点；避免同一处出现多条无实际含义的小标签。
- **圆润但不幼稚**：卡片圆角 16～25px，按钮 12px，输入区 10～13px。
- **书写体验优先**：长文阅读具备合适行距，编辑器不渲染复杂光标行效果。
- **两套模式**：暖纸色和深夜墨色，通过 CSS 变量维护。
- **字体**：用户自备的 `titlefont.ttf`、`textfont.ttf`，支持系统字体兜底。

## 组件层级

- 主导航：5 个固定入口，写作作为单独强主操作。
- 页面标题：32～40px 中式标题字体，只有一行简短说明。
- 数据与列表卡片：轻背景，柔和边框，弱投影。
- 主要 CTA：深绿；辅助操作：白底细边。
- 一次只使用一种突出状态：进行中、危险或当前选中。
- 手机上导航折叠为图标 + 短标签的五列布局，不依赖横向滚动。

## 可维护性

基础变量在 `src/styles/foundation.css`，布局在 `layout.css`，控件在 `controls.css`，页面细节在 `pages.css`，断点在 `responsive.css`。
