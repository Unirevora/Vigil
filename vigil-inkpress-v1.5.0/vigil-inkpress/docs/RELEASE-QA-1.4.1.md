## 需要真实部署环境核验的事项

1. 当前自动化浏览器通过 `about:blank` 内联装配项目验证 UI，此环境缺少 `crypto.subtle` 安全上下文；加密函数已用 Node Web Crypto 测试，但浏览器文件下载与密码解密的真实流程应在 `http://localhost:5173` 或 HTTPS 下最终验收。
2. 真正的 GitHub 远端提交和 Token 授权需要用户自己的仓库；这里沿用上一版经过模拟 API 验证的功能，没有使用用户账号执行写操作。
3. 从旧项目 v2.8.2 迁移加密备份仍需原始加密协议或样本；新版 v1 独立加密格式不声称兼容。
4. 自有 `titlefont.ttf`、`textfont.ttf` 未打入源码交付 ZIP；可运行 `scripts/restore-fonts.py` 与 `scripts/pack-with-local-fonts.py` 在用户自己的设备恢复。
5. 使用者仍应通过实际个人数据进行备份/恢复演练，不要只依赖浏览器的同设备本地快照。

## 发布边界

这一版为可运行的本地优先原型迭代，包含生产可读的源代码、测试与资产，不是跨设备加密同步服务。
