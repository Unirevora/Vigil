## 运行边界

- 编辑器使用项目内置 CodeMirror 5，文本内容仍是单一 Markdown 字符串。
- KaTeX 使用本地 MathML 输出，不打包系统字体与外部下载字体文件。
- 自选图片使用 IndexedDB Blob 而非 localStorage，个人数据与偏好分离。
- 备份导出只包含正式手记，不打包个人背景照片和草稿。
- 旧版 v2.8.2 的真实加密导出格式、浏览器私密入口与历史 schema 需要源码和样本，不能凭更新日志推断兼容。

参见 `EDITOR-1.4.2.md`、`LIQUID-GLASS-1.5.md`、`GIT-CRYPT-1.5.md`、`PRODUCT-STRATEGY-1.5.md`、`QA-1.5.md`。
