# 不眠手记 1.5.1 · 一张稿纸的实时排版

此文档对应 `src/editor/unified-editor.js`、`src/editor/live-markdown.js`、`src/core/markdown.js` 和 `src/styles/editor-refine-151.css`。

## 修复的真实原因

1. 1.5 的实时模式主动跳过光标所在行的 Markdown 装饰，造成当前行只有源码、没有排版。现在**活动行保留原 Markdown 标记，同时正文仍应用加粗、斜体、标题、引用、列表、代码与链接样式**；只有离开后才隐藏部分标记。
2. 1.5 阅读模式隐藏了 CodeMirror 元素，却仍让它的父容器保留约 510px 最小高度。现在切换到阅读模式时会同步更新稿纸容器的 `data-mode`，并彻底隐藏编辑器宿主，不再占位。
3. 旧解析器把普通段落的每一次源码换行渲染为 `<br>`，连续空行与较大的段落间距叠加。现在普通软换行合并为自然段；只有行尾双空格或反斜杠才保留硬换行，连续空行不产生空段落。
4. 旧 KaTeX MathML 的行内公式在部分 Chromium 布局中占满段落宽度，导致标点孤行。现在为行内 MathML 使用内在宽度的可换行周边盒，公式紧邻句子显示。

## 三种模式

| 模式 | 行为 | 数据安全 |
| --- | --- | --- |
| **实时** | 当前行源码标记可见，正文同位加粗/斜体/标题；`$...$` 源码旁即时显示 KaTeX；失焦行隐去部分标记 | CodeMirror 始终保有唯一 Markdown 原文 |
| **阅读** | 同一张稿纸的完整排版，不展示编辑器宿主；不虚构空行 | 不保存 HTML，仅仅读取 Markdown |
| **源码** | 所有 Markdown 记号按原样显示并保留语法高亮 | 原 CodeMirror 对象与撤销历史继续保留 |

### 活动行如何同时显示两种形态

- 输入 `## 标题`，字会立即切换为标题字号，同时 `##` 保持轻微朱砂色的可编辑标记；光标离开后才隐藏 `##`。
- 输入 `**重要**`，当前行可见 `**` 标记，但“重要”已是加粗字；离开当前行仅隐藏边界标记。`*斜体*`、`~~删除线~~`、反引号代码与内部链接同理。
- 输入 `$x^2$`，源串保留在当前行，旁边插入**不参与保存**的 KaTeX MathML 公式书签；离开编辑行后用公式替换源串的视觉显示。源码、选区和撤销记录不被改写。
- 块级公式、表格、代码围栏在编辑时保留原始块并在块末尾显示预览；离开整块后可以折叠为同页渲染块。
- 超过一行的连续空白只在**非编辑状态**收拢。再次进入这些行时，CodeMirror 的装饰会被撤销，原始空行仍存在。

这不是 Obsidian 本体，也**不声称所有 Markdown 插件/嵌套 token 均已完全复刻**。高度嵌套的强调、HTML、复杂多行表格等仍可能退回源码样式；完整 CommonMark 解析与协同光标是后续工作。

## 编辑器布局与功能

- 一张稳定、实色、宽度受限的稿纸承载全文，避免玻璃效果影响书写光标。
- 标题为主信息，日期、心情、标签折入「手记信息」；原字段和保存逻辑完全保留。
- 工具栏只常驻加粗、斜体、标题、列表、链接、行内公式、撤销、重做；引用、代码、删除线、任务、块级公式、表格移到「更多」菜单。
- 三种视图切换采用轻量分段控件；大纲是可展开的按标题跳转面板，在编辑时自动更新。
- 保留原有查找/替换、沉浸书写、Markdown 任务勾选、自动保存草稿、五份本地备份，以及 `Ctrl/⌘+S` 正式存档。撤销/重做作用于 CodeMirror，不复原渲染 HTML。
- 手机默认收起多行侧边导航，顶部仍有菜单入口。工具栏在窄屏紧凑换行，但仍是**一个编辑窗口**。
- 支持系统 `prefers-reduced-motion`，不对正在输入的文本施加弹性动画。

## 兼容性与隐私

- 仍保存原来的 Schema v1 JSON；不会将 MathML、装饰片段或渲染 HTML 写入正文。
- KaTeX 0.16.27 为项目原本内置的离线版本，`trust:false`，MathML 不需要额外安装字体。
- 原有 GitHub 远端 Markdown、git-crypt、节气盘、任务聚合均未改动其存储格式。
- 1.5.1 不更改 `vigil-mvp-data-v1` 等已存在的存储 Key；外观旧背景 Key 读取时会迁移到新内置背景。

## 测试

`npm test` 覆盖格式片段、标题和列表、代码围栏、KaTeX、软/硬换行、空段落、背景迁移；`scripts/qa-editor-151.py` 的 Chromium 验证包括活动行源文+排版、公式、阅读占位修复、空行、模式切换、撤销、保存重开、大纲、主题持久化与 6 种宽度。
