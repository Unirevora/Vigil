# v1.4.1 · 纸页回弹与侧栏交互

## 视觉基准

严格保留 v1.4.0 的深绿文房、铅字印章、暖宣纸、黄铜线、水墨山水和打字机静物。动效仅用于强调操作结果，不能改变内容、位置语义或打断书写。

## 回弹规则

| 组件 | 动作 | 约束 |
| --- | --- | --- |
| 按钮 | hover 微抬 3px、active 轻压并回弹 | 不使用大幅缩放 |
| 手记卡片 | hover 微悬浮、轻微旋转 | 不改变 DOM 次序 |
| 导航项 | 横向 2–3px 反馈、选中印章图标轻弹 | 依旧支持键盘焦点 |
| 首页静物 | 9 秒微幅呼吸，幅度 <1% | 装饰层不截获点击 |
| 弹窗 | 落纸式入场、一次轻回弹 | 文本和按钮保持稳定 |
| 页内内容 | IntersectionObserver + WAAPI 进场，stagger ≤ 272ms | 只动 transform/opacity，离屏项等到可见 |
| 节气盘 | 保留 v1.3 轮盘惯性过渡 | 系统减少动效时禁用 |

`src/ui/motion.js` 是独立脚本，`src/styles/motion-141.css` 提供动效与侧栏布局。采用媒体查询 `prefers-reduced-motion: reduce` 关闭装饰动效和页面过渡，不要求用户额外调整设置。编辑器输入本身不会触发页面重新渲染或卡片回弹。

## 桌面侧边栏

- 默认展开，宽度与 v1.4.0 原站一致，图文齐全。
- 点击侧栏边界的浅纸折叠按钮，收缩为 79px 左侧图标栏。
- 六个导航入口、主新建按钮保持实际可点击、可通过 Tab 焦点访问；每个导航项有 `title` 提示。
- 折叠按钮更新 `aria-expanded`、`aria-label`、`aria-controls`。
- 仅保存布局布尔偏好：`vigil-sidebar-collapsed-v1`；不修改手记存储格式。
- 视口进入平板/手机宽度时转为水平手机头部，不用桌面折叠状态覆盖手机菜单状态。

## 手机导航

- 页面顶部保留品牌印章和快速写作入口。
- 右上角菜单按钮可独立切换六个导航入口显隐。
- 选择导航后自动关闭菜单，`Escape` 也可以收起。
- `vigil-mobile-nav-open-v1` 是独立本地偏好，不污染桌面。
- 手机入口展开时仍保留六列短标签；320px 也能完整操作。

## Ctrl/⌘ + K 快捷命令

- 任何主要页面可用：顶部放大镜按钮或键盘 `Ctrl/⌘ + K`。
- 搜索的是本地正式保存的手记：标题、正文与标签均可命中，包括旧手记（不限制为最近 300 篇）。
- 快捷操作：新建、切换六个一级页面、收藏筛选、继续最近草稿、打开匹配笔记。
- 面板只展示最多 11 条候选，防止长列表阻塞 DOM。
- 方向键移动焦点项、`Enter` 打开、`Escape` 取消、鼠标点击选中。
- 选择操作仍调用主项目现有的 `leaveTo`、`startEditor`、`readEntry`，沿用草稿保存失败拦截。
- 用户输入的标题和正文搜索内容通过 `textContent` 填写，不作为 HTML。
- 若已有需确认的模态框或加密口令弹窗打开，不开启命令面板。
- 命令面板并不是远程搜索，也不会向 GitHub 发送手记内容。

## QA

- Chromium 验证桌面 1440px 折叠由 >220px 缩到约 79px。
- 320、390、810、1024、1440、1672px 各页面无横向溢出。
- Ctrl+K 打开、搜索节气、Enter 跳转，Esc 退出及手机收起菜单已验证。
- 加密模块的实际 Web Crypto 需要 `localhost` 或 HTTPS；不要直接以 `file://` 打开项目。
