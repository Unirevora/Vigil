## 验证环境限制

当前运行沙盒中 Chromium 通过 `page.goto(http://localhost:...)` 会报 `ERR_BLOCKED_BY_ADMINISTRATOR`，因此网页交互检查使用了**将项目实际源码/样式及静态资源装配成离线页面的 Chromium 夹具**。它能够验证 DOM、CSS、列表交互与 Blob 导出，但**不是正式 localhost/HTTPS 环境的端到端覆盖**。

GitHub 私有仓库授权、远端实际提交、git-crypt 的用户实际密钥和旧版私有数据迁移未在此次执行。这些操作需要真实账户、实际仓库或源数据，不能将模拟检查视为完成实连。

用户自备 `titlefont.ttf`/`textfont.ttf` 仍未重新分发，源码使用本机已配置的原有字体路径；没有字体时回退到系统字体。
