# 1.5.1 · 高分辨率、低噪声的背景方案

## 设计原则

这里的背景不再作为主要信息内容：保留大面积留白，山峦/水纹只作低对比远景，**正文面板始终为稳定不透明的纸张**。悬浮导航/搜索使用原有节制的液态玻璃，不把玻璃铺到长文或表格上。

| 设置项 | 资源 | 技术 | 表现 |
| --- | --- | --- | --- |
| **素笺** | `assets/wallpaper-paper.svg` | 可无损缩放的矢量 | 暖白底、极浅远山形状 |
| **晨雾** | `assets/wallpaper-mist-3200.webp` | 3200×1800 WebP | 低饱和浅青晨景，云雾山脉在下方 |
| **青绿** | `assets/wallpaper-sage.svg` | 可无损缩放的矢量 | 极简青绿渐层与起伏线条 |
| **月夜** | `assets/wallpaper-moon-3200.webp` | 3200×1800 WebP | 墨绿月夜与远山，适合深色界面 |
| **我的背景** | IndexedDB 内的用户图片 | 本机 WebP 转换 | 与主题偏好分离存储，不上传 |
| **纯色** | 无图片 | CSS 实色 | 专注写作、最小干扰 |

**图片说明：** 两张 WebP 经过高质量插值导出为 3200×1800，原始图像分辨率约 1672×941；插值提升显示尺寸与梯度平滑度，不冒充存在额外原始摄影细节。SVG 为真正的分辨率独立图形。

## 旧用户偏好兼容

原版本中 `plum`（疏梅）、`bamboo`（竹影）、`waves`（海波）不再作为内置背景选项；读取到这些历史值时分别映射到 `mountains`、`sage`、`sea`，主题色/纸张/字号及其他用户数据不变。

首页仍保留原复古打字机静物，用户上传的自定义首页照片也不受背景迁移影响。删除旧 `landscape-ink-hd.webp` 和 `landscape-ink-deep.webp` 后，光学玻璃采样资源统一引用新的背景素材，不会从旧图中取样。

## 新的视觉节奏

- 首页保留一个强视觉主体；卡片和正文取消冗余纹样/双重边框。
- 编辑器是单一稿纸，工具栏紧凑，日期/标签收纳而非铺满屏幕。
- 全局采用清爽浅纸 + 墨绿导航 + 少量朱砂状态点；深色模式维持对比度。
- 手机端默认折叠侧边导航，保留明显的展开按钮；宽度 320px 起不会横向溢出。
