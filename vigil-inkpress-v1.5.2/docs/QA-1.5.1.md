## 浏览器环境说明

当前测试环境限制浏览器导航到 `localhost` 与自建主机名，因此使用 `scripts/make-inline-qa.py` **仅在测试时**将真实模块转为一次性独立作用域并装入 Chromium；交付应用本身仍为 ES Modules 的多文件网站，不是单 HTML。测试脚本可通过 `python scripts/qa-editor-151.py` 重复执行，需要安装 Python Playwright 和 Chromium。

没有在这里声称已经连接你的真实 GitHub 仓库，或者已经以真实用户数据执行旧版加密格式迁移。GitHub、git-crypt 模块原有单元测试仍在 74 项测试集中；这次没有改变其加密文件格式。
