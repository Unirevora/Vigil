# 不眠手记 · 重构版更新日志

## v1.3.0 · 风物入笺（2026-11-13）

### 设计回归
- 重新以 v1.1「铅字旧梦」为视觉基准：深墨侧栏、朱砂印、暖宣纸、黄铜边、墨绿旧式打字机。
- 恢复原 v1.1 打字机模型与纸面叠层，不再使用 v1.2 的替代信笺装饰。
- 在保留复古质感前提下整理圆角、卡片层级、导航与信息密度。
- 六个主要入口：卷首、全部手记、日历归档、节气风物、GitHub 仓库、门与数据。

### Markdown 实时预览
- 写作页左右源码/实时安全预览，手机上下排列。
- `requestAnimationFrame` 同步渲染，不重建源码 textarea，保持输入法、光标、撤销与文本选区。
- 按比例同步预览滚动，增加专注模式与输入状态。
- 保留自动草稿和正式存档、Markdown 工具栏。

### 节气风物与日历
- 新增 24 节气与 72 候的独立纯函数模块。
- 新增可拖动/触摸/滚轮/键盘操作的节气轮盘、节气名直达、空闲回今天。
- 增加传统三候、近似月相、农历文字与 24 句原创节令短笺。
- 日历标注节气日期与手记日，点击日期显示当日笔记、节令、短笺，可直达风物。
- 2026 关键节气日期加入单元测试，明确天文近似与 UTC+8 边界。

### 工程与数据
- 延续 v1.2 GitHub Markdown 仓库预览、提交与 SHA 冲突保护。
- 延续独立草稿、五份本地备份、JSON 导入导出以及可选标签/收藏数据结构。
- 提供 `scripts/pack-with-local-fonts.py`，允许用户在本机从自有原始 ZIP 创建包含字体的整包；本交付包不附加字体二进制文件。
- 增补设计溯源、风物计算说明、完整接口文档与回归测试。
