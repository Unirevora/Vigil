# 不眠手记 v1.5.5 · 同题同序

本版保留 1.5.4 的复古墨绿/朱砂/宣纸与毛玻璃组件，更新重点是**让每个功能页有同一套清晰的标题层级**，并让列表真的能帮助你找到需要重读的手记。

## 统一标题

- 顶栏只保留设置、检索、当前日期、日间/夜间主题四项，不再显示重复的小号页名。
- 全部手记、日历与风物、线索与行动、GitHub、设置页共享一个页面标题组件 `src/ui/views/page-heading.js`。
- 桌面标题约 48px（根据视口有 36–52px 的流式变化），主内容位置上移；手机缩放到 31–38px。
- 首页保留视觉稿中的英雄标题，阅读和编辑页以文稿标题作为页面主标题，不重复添加「阅读手记」之类的假标题。

## 快速筛选

进入「全部手记」后，可以组合以下条件：

- **收藏**：只看已经收藏的手记，再点一次取消。
- **最近 7 天**：以设备当前日为结束，包含今天及之前六日，不包含未来日期。
- **有待办**：扫描 Markdown 中未完成的 `- [ ]`、`* [ ]` 或 `1. [ ]` 等任务。位于 fenced code blocks 中的示例不计入任务。
- **标签**、**日期/月份**和**标题/正文关键词**：继续沿用原有筛选；可与上面两个快捷条件组合。
- **全部**与**清除条件**：一键重置关键词、日期、标签和智能筛选，不改变手记内容。

输入关键词时，页面顶部的结果数与列表数量会同步更新。结果为空时显示「没有找到相关手记」，不会误认为所有手记丢失。

## 只导出当前筛选结果

手记列表右侧新增「导出当前结果」，点击后下载 `vigil-selection-YYYY-MM-DD.json`。

- 文件使用正式 Schema v1，与普通 JSON 导入结构一致；只包含当前搜索/筛选命中的正式手记。
- **导出不删除、不修改、不移动**正式手记；当前结果为零或文库处于只读保护时按钮禁用。
- 它不是加密导出，不包含草稿、背景图片、本地备份或 Github 远端内容。若要保密分享，请使用设置 → 数据中的加密导出。

## 键盘快捷操作

在「全部手记」页，按 `/` 会快速聚焦列表搜索。若正在输入框、编辑器或可编辑文本中输入内容，斜杠保持原来的文本输入行为。

其他快捷键仍保留，例如 `Ctrl/⌘ + K` 命令面板与编辑器格式快捷键。

## 运行与升级

```bash
npm run dev
```

打开 `http://127.0.0.1:5173/`；Node.js 18+。原本的本地 JSON Schema、草稿、备份和外观偏好未改动，不需要手动迁移。

本地隐私仍以浏览器沙盒为边界。首次升级前建议从旧版本「设置 → 数据」导出一次完整 JSON。
