# VIGIL Heritage v1.3 · 视觉体系

**传承基准：v1.1「铅字旧梦」**，不是 v1.2 的清淡柔灰极简方案。

## 保留的 1.1 识别元素

- 以墨棕色侧栏承托导航，朱砂红「眠」印章为品牌记号。
- 首页保留原有 CSS 打字机、打字纸、黄铜滚轴与朱砂小印章的层叠结构，避免改回纯装饰信纸插画。
- 用暖旧纸色、浅奶油纸、灰绿机械漆、黄铜线和墨黑组合。
- 标题采用原 `titlefont.ttf`，正文采用 `textfont.ttf`；用中文字体为主，英文仅作为极少量刊印点缀。
- 文书、阅读、编辑的纸面带极轻的砂纸颗粒和一条朱砂左边线。

## 调整而非替换

- 卡片圆角：14–22px，主框更柔和，不改成透明玻璃拟态。
- 控件圆角：10px，保留纸质按钮的轻阴影与机械按压反馈。
- 信息层级：标题为第一层，日期/状态为第二层，辅助解释不重复出现。
- 深色模式保留墨色侧栏，正文纸面切为暗灰绿墨纸，不采用饱和霓虹。

## 组件与模块

- `src/styles/typewriter.css`：从 v1.1 保留的打字机 CSS 层叠素材。
- `src/styles/heritage.css`：继承 1.1 的综合色板与组件精修。
- `src/styles/live-editor.css`：源码/预览双栏写作纸面。
- `src/styles/almanac.css`：圆盘、三候与短笺。
- `src/styles/responsive.css`：320 / 390 / 810 / 1440px 断点下减少拥挤。
- `src/styles/foundation.css`：保留 `@font-face` 字体引入与底层 CSS 变量定义，再由 `heritage.css` 覆盖视觉版本。

所有动态和过渡遵守 `prefers-reduced-motion`。

## v1.4.1 · 有呼吸的纸页

- 保留 v1.4.0 实际参考图的墨绿、朱砂、旧纸、书桌和金线纹样，不另建一套视觉系统。
- `--vigil-spring: cubic-bezier(.18,1.28,.33,1)` 用于按钮、菜单与轻量卡片的形变反馈；以 <=6px 的位移和 <=1.5% 的缩放作为常规范围。
- 桌面侧栏 79px 折叠态仍展示图标和朱砂选中状态；侧栏折叠按钮作为纸页铰链悬浮在内容边界。
- 命令面板采用暖纸层与墨绿遮罩；加密备份采用朱砂窄竖线和小方印，不引入强烈警示色大卡片。
- 小屏时保留六个真实导航入口，可通过顶部菜单按钮收起。
- 所有动画提供 `prefers-reduced-motion` 退化路径，输入/滚动内容不因动效丢失焦点。

## v1.4.2 · 一纸三观与外观工坊

- 深墨侧栏、朱砂印章、黄铜框、宣纸、梅花和打字机的 v1.4.1 视觉基调完整保留。
- 主题色运行时覆盖 `--appearance-accent`、`--accent` 等视觉 token，未修改用户手记 Markdown 或安全存储。
- 可配置全局背景层（纸纹/山水/竹/梅/浪纹/自选照片），调节背景不透明度和纸面遮罩。
- 以 CodeMirror 为单一 Markdown 源文控件；三个视图入口是同一个容器上的小型页签，不再出现第二个文字窗口。
- KaTeX 数学公式采用原生 MathML 表达，样式偏旧书卷气，不加载第三方字体二进制。
- 沉浸写作在同页临时隐藏导航，不更改原有页面路由和数据状态。
- 新样式分别在 `appearance-142.css` 与 `editor-142.css`，最后加载以避免覆盖既有墨绿文房细节。

## v1.5.3 · 澄墨与统一色阶

- 色彩不再停留于点缀：侧栏、主按钮、选中态、弹出菜单与光学控件共享源 `--appearance-accent`，派生深色侧栏与浅染玻璃。
- 毛玻璃只用于导航、工具栏、搜索和临时弹层；普通内容/阅读区域仍是不透明的稳定纸面。
- 设置页采用四个扁平文字选项卡，复杂内容分组使用 1px 分隔线；避免叠四层卡片。
- 下拉选择采用项目自有的浮层菜单，但原生 select 保持状态源，确保旧业务逻辑和可访问性。
- 侧栏透明度、模糊度、悬浮控件着色和动效强度均在设置中心保存。

## v1.5.4 · 岁时合卷的轻量层级

- 顶栏是内容区域的一部分，不是覆盖所有页面的玻璃遮罩：透明页头 + 1px 分隔线，当前页文字使用 20–26px，中间不夹 `V.` 纹样。
- 只有搜索、设置、明暗按钮维持轻透玻璃与独立高光；侧栏保留用户动态主题色毛玻璃。
- 设置选项卡使用一块 **紧凑圆角底座**，整体宽度由 5 个标签内容决定，不横向铺满；活动项使用弱主题染色小圆角。正文设置面板仍然不透明，宽屏圆角 26px。
- 日历和节气是同一页的两个视图：顶部统一标题、日期摘要，卡片保持素纸实色，不在轮盘上叠加额外玻璃。
- “关于”不再堆叠小卡片；使用编年小节、细分隔线与本地状态检查行，减少视觉噪音。
- 320–1672px 均考虑：手机底部快捷导航改为「岁时」，桌面则保留折叠侧栏；受 `prefers-reduced-motion` 控制的回弹交互不变。

## v1.5.5 · 同题同序

- 顶栏只承担全局操作，不重复输出当前页面名；每个主要功能页只保留一个主标题。
- `src/ui/views/page-heading.js`：通用 `<header class="page-head page-titlebar">`、`h1.page-title`、副标题、可选结果数和主操作按钮。
- `src/styles/vigil-155.css`：专门维护统一的标题字体、间距和断点，避免多份历史 CSS 的字号规则互相覆盖。
- 桌面主标题 `clamp(36px,3.35vw,52px)`、行高 `1.14`、字重 600、字距 -0.025em；平板 `34–43px`、手机 `31–38px`。正文描述 13px、行高 1.65。
- 首页英雄和手记正文标题不按模块页标题重复输出；读写时的真实文档标题与全局标题在字号体系上一致，但保留文稿语义。
- 智能筛选是轻量丸状控件，不变成卡片墙；当前结果导出是右侧小型文字操作。
- 保持原墨绿/朱砂/暖纸/山水、动态主题侧栏及独立玻璃控件，不为统一标题引入新的大背景、强高光或大面积遮罩。
