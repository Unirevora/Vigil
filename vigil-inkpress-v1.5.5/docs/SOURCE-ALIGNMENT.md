## 关键设计取舍

- **不抛弃 v1.1**：保留 v1.1 原始 CSS 打字机外观与深墨色竖侧栏，保留边框、纸纹、黄铜感阴影、朱砂线；圆角柔化控制在 10–22px。
- **不重新塞满小字**：去除无意义编号，首页信息由视觉主体、统计、今日节令与最近手记构成；风物页仅有节气盘、当期节令、三候、短笺四层。
- **实时 Markdown 是纯显示更新**：使用 `requestAnimationFrame` 更新只读预览 DOM；textarea 不发生 DOM 替换。并不声称是 Obsidian 级 token 混排。
- **节气与天文数据**：节气历日按照太阳视黄经近似计算，UTC+8；月相为平均朔望周期示意，不能替代天文台精密数据。短笺诗句是当前项目原创表达，并非原更新日志中未提供的具体古诗句。
- **数据不越权**：GitHub 工作区继续独立于本地手记；不在没有用户授权或实际仓库的情况下提交。
- **字体保留引用**：本次不修改用户所提供的 `VigilTitle`、`VigilText` 路径及字体使用范围；通过本地脚本允许用户从其原始项目创建包含字体的自有整包。
