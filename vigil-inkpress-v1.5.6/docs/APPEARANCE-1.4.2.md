# VIGIL 1.4.2 · 外观工坊

## 设置入口

桌面左侧「外观设置」或顶栏齿轮按钮。手机端使用顶栏齿轮。

## 已提供

1. **主题色**：朱砂、松绿、黛蓝、铜金、梅紫、墨青六种预设及浏览器颜色选择器。
2. **背景**：旧宣纸、远山、疏梅、竹影、海波、素笺六种方案及自定义图片。
3. **图片上传**：支持 JPG、PNG、WebP、GIF，默认取静态画面，长边自动缩到 1920px 以内并转为 WebP，原文件限制 12MB，压缩后不超过 3MB。使用 IndexedDB 保存 Blob。
4. **首页静物**：保留参考图中的原复古打字机，或更换为自己的案头图片；两个图片槽分别保存。
5. **外观可调**：背景透明度、纸面遮罩、正文字号、行距、画布最大宽度、宣纸颗粒开关。
6. **书写字体**：原版用户字体路径、系统宋体、黑体、楷体；如果字体未复制到项目中的 `fonts/` 文件夹，自动回退至系统字体。
7. **纸面昼夜**：浅色纸张/墨夜模式。与原有顶栏切换按钮共用一份主题设置。
8. **恢复经典外观**：恢复墨绿文房默认视觉，不触动任何手记、草稿、备份或 GitHub 令牌。

## 数据隔离

| 键 / 存储 | 内容 |
| --- | --- |
| `vigil-appearance-v142` | 安全的数值/枚举外观配置，无原始图片文件 |
| IndexedDB `vigil-appearance-image-v142` | 背景和首页静物压缩 Blob，两个 key：`background` / `hero` |
| `vigil-theme-v1` | 兼容旧版主题切换，保存昼夜偏好 |
| `vigil-editor-mode-v142` | 记住最近使用的实时/阅读/源码模式 |
| `vigil-mvp-data-v1` | 原手记正文，结构**不变** |

**图片仅存当前浏览器，未发送到服务器。** 清除浏览器站点数据会删除图片偏好。JSON 手记导出**不包括**个性化图片或外观设置；需要跨设备迁移图片请自行保留源文件。

## 限制

- 图片操作使用浏览器 `createImageBitmap` 和 IndexedDB；需在正常 HTTP/HTTPS 站点环境下使用。`file://` 下 ES Modules 本身不受支持。
- 不支持自定义任意 CSS、上传外部脚本或加载第三方字体网址；主题色仅允许六位十六进制 RGB，以降低危险的 CSS 注入风险。
- 深色模式仍保留复古纸张和深绿侧栏；自定义背景在深色下可能需单独降低亮度。
- 预设背景使用项目已有装饰素材，不会另行下载图片。
