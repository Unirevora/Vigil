# 不眠手记 · 重构版更新日志

## v1.2.0 · 文房简序

### 视觉与信息架构
- 全面调整为圆角柔和的中式复古纸张设计；降低画面噪音。
- 精简侧边栏、顶部栏、英文装饰文案和辅助说明，保留清晰的主操作。
- 重构首页卡片、列表卡片、编辑器、阅读器、日历与数据管理。
- 深夜墨色主题与暖纸主题双模式。
- 针对手机优化五个固定导航入口。

### 设计文档的 P1 功能
- 手记新增标签、心情、收藏（Schema v1 可选字段兼容）。
- 支持收藏/标签搜索筛选、月份归档、日历浏览与往年今日。
- 写作工具栏与独立 Markdown 预览开关。
- 阅读视图上一篇和下一篇导航。
- 延续草稿自动保存与五份本地历史备份。

### GitHub 仓库集成
- 公开仓库匿名目录与 Markdown 预览。
- 支持指定 GitHub 仓库、分支、笔记文件夹。
- fine-grained PAT 临时授权私有仓库、Markdown 修改和创建。
- GitHub Contents API 写入 Base64 UTF-8 内容。
- 以 Git blob SHA 检查并发修改冲突，避免盲目覆盖。
- 仓库配置本地保存，令牌仅在 JS 内存中保存、可断开清除。
- GitHub 远端和本地手记分离，没有自动双向同步。

### 测试
- 新增 GitHub API、P1 条目模型、日历运算测试。
- 桌面与手机的关键交互、远端模拟提交和跨旧版 Schema 兼容测试。

## v1.1.0 · 铅字旧梦
- 近代铅字印刷风格与模块化布局。
- 独立草稿区、本地五份备份及恢复、危险操作备份保护。
- 基础 CRUD、Markdown、JSON 导入导出和旧原型迁移。
