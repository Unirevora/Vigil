# VIGIL 1.4.2 · 一纸三观 Markdown 编辑器

## 三种模式，同一文稿

- **实时渲染**：基于 CodeMirror 编辑控件。当前活动行保留原始 Markdown 记号以保障输入体验；离开编辑的行自动隐藏部分 Markdown 标记并显示排版（标题、粗体、斜体、删除线、行内代码、链接、任务列表、表格）。完成且不在活动范围的公式由 KaTeX 转换为 MathML 显示。
- **阅读模式**：隐藏 CodeMirror 编辑表面，在**同一份纸张容器**中展示完整只读 Markdown 排版，包括行内和块级公式、表格、任务列表及 `[[同名手记]]` 站内链接。
- **源码模式**：恢复原始 Markdown 文本、语法高亮，不折叠任何文本记号。

三种模式不会替换底层文稿的 CodeMirror 实例，保留原始字符串、历史、选择与撤销记录；自动草稿、正式存档依旧只保存 Markdown 文本而非 HTML。切换到其他手记时会卸载编辑控件，重新打开从保存的 Markdown 重建。

这是一套**接近 Obsidian Live Preview 的可维护实现**，不是 Obsidian 自身编辑器的逐 token 精确复刻。嵌套复杂 Markdown、跨段落复杂语法等仍可能以源码形式呈现，格式编辑时光标所在行会恢复 Markdown 标记。

## KaTeX 本地实时排版

- 使用真正的 KaTeX v0.16.27（本项目 vendor 目录内的本地 ESM 版本），不依赖 CDN。
- 通过 `output:'mathml'` 输出浏览器原生 MathML；**不随交付包分发 KaTeX 字体二进制**，仍能完成公式解析与数学排版。
- 默认 `trust:false`，`throwOnError:false`，限制公式长度及展开次数；危险宏不被授权。
- 行内语法：`$E=mc^2$` 或 `\(E=mc^2\)`。
- 块级语法：单独的 `$$` 两行围住多行公式，或 `\[` 与 `\]`；也支持单行 `$$...$$`。
- 光标进入公式所在行，显示可编辑 TeX 原文；离开后恢复公式排版。数学式可由工具栏 `ƒx` / `∑` 插入。
- 正式阅读页、同窗阅读模式也会用相同的 KaTeX 渲染流程；并不会修改存储的正文。

示例：

```markdown
# 随笔里的数学

勾股定理 $a^2+b^2=c^2$。

$$
\sum_{k=1}^{n}k=\frac{n(n+1)}{2}
$$
```

## 增补写作工具

- 工具栏：加粗、斜体、标题、列表、引用、代码、链接、行内与块级公式、任务清单、表格。
- 行内 `- [ ]` / `- [x]` 任务清单可以点选，点选直接改写 Markdown 源文，不是另存一个状态。
- `[[手记标题]]` 在阅读视图中可跳转到同名正式手记。找不到标题可确认创建同名手记。
- 当前文稿的查找/替换：`Ctrl/⌘ + F` 调出搜索条，`Ctrl/⌘ + H` 聚焦替换，支持上/下一个及全部替换。
- `Ctrl/⌘ + E` 在实时模式与阅读模式间切换；源码模式可以通过上方三段模式选择切换。
- **沉浸书写**：稿纸栏右上角按钮或 `Ctrl/⌘ + Shift + F` 隐藏侧栏和顶栏；Esc 返回正常视图。
- `Ctrl/⌘ + S` 正式存档，并继续使用既有五份备份策略。

## 交互与数据安全

- Markdown 源文是唯一事实数据源，所见即所得区域只是装饰（CodeMirror marks）或只读视图。
- 浏览器中文输入法、光标、选区、撤销/重做由 CodeMirror 管理，组件不直接替换正在输入的 DOM 节点。
- 复杂语法的装饰采取视窗附近渲染；超大文件仍需在真实数据量下做性能测试。
- 预览 HTML 中的用户正文先转义再加入受限的 Markdown 标签；外链仅允许 HTTPS/HTTP/mailto。KaTeX `trust:false`，防止执行输入中的 HTML 或危险命令。
- 传统本地库和 JSON Schema v1 不变，GitHub 远端 Markdown 工作区仍独立管理，未擅自合并。
- 公式使用 MathML 以不分发字体；推荐现代 Chrome/Firefox/Safari。字体排版细节与 KaTeX HTML+字体模式略有不同。
