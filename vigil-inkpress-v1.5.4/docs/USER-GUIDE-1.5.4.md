# v1.5.4 · 合并页、设置与关于

## 日历与风物

点击主导航 **日历与风物** 即可进入。左侧/上方的切换控件有两个页签：

- **日历归档**：浏览某个月的手记标记、节气日期、所选日的历史文字、月份归档和往年今日。
- **节气风物**：24 节气盘、传统三候、农历文字、月相近似示意和节令短笺。

在日历选中某一天后切到节气，会看到**同一日**的节令。节气盘拖动、点击节气或用滚轮/键盘改变日期后，切回日历会回到所选日对应月份。页签支持 `←`、`→`、`Home`、`End`。点击右上「回到今天」同时重置两个视图。该节气模型支持 1901–2099 的风物日期。

旧页面按钮/内部命令中的「日历归档」与「节气风物」都转入这个合并页，已有手记的日期、标签和收藏不发生变化。

## 设置中心

现在设置有 5 个紧凑页签：**外观、排版、交互、数据、关于**。页签宽度跟随内容，不再拉伸成横向整行矩形。`←`/`→` 在相邻页签切换，`Home`/`End` 跳到首尾。恢复经典外观按钮只显示在与外观相关的页签。

## 关于页面和诊断

「关于」展示版本、当前设备记录概况、数据隐私说明以及文档入口。

点击 **开始检查**，会在本机检测：

- 本地存储的读写能力与数据库存在性；
- HTTPS/localhost 的安全上下文和 Web Crypto；
- Markdown 编辑器、KaTeX 是否加载；
- 文库是否被异常保护为只读模式；
- GitHub 工作区当前是否连接（**不是**远端连接可靠性的实时检测）。

点击「复制诊断摘要」只复制上述检查结果和记录数量。**不会**包含任何手记正文、标题、仓库所有者、密钥、Token 或背景图片。用户没有点击按钮时不主动运行诊断，不会上报远程服务。

注意：浏览器本地备份与正式手记同设备存放，清除站点数据后会一起消失。长期保存请进入「设置 → 数据」导出文件。
