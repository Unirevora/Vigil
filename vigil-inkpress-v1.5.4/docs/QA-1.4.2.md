- `npm test`：**55 / 55** 项 Node 单元测试通过，包含数学排版、阅读器安全、设置白名单、编辑模式持久化、旧版数据兼容、加密文件往返、GitHub API 模拟与数据操作测试。

- 素材只用于装饰，首页的导航、按钮、统计和手记数据仍由真实 DOM 驱动。

## 需要环境复验的范围

1. 这里的浏览器回归使用内联编译的原生源代码镜像运行，避免测试环境对本地网站浏览器访问的限制；**没有声称使用真实远程部署环境验证模块下载**。已经在 HTTP 层确认本地开发服务器能够正常提供各模块及素材。
2. 自定义背景的上传、IndexedDB Blob 持久化与重新打开功能使用标准浏览器 API，尚未在当前隔离环境下完成真实 HTTP Origin 的上传闭环。请在项目 `npm run dev` 下首次运行时验证。
3. GitHub 连接和提交需要用户自己的 PAT / 仓库，未触碰真实账号。
4. 原始完整项目 v2.8.2 的加密文件和数据样本缺失，新加密备份格式不保证读取旧文件。
5. 输入法细节在多个 Chromium 交互流程间接验证，仍建议用户在真实设备上分别实测中文、日文输入及极长文稿。
6. 文件交付不附带原用户自备字体或任何 KaTeX 字体文件。标题和文本字体路径保留，KaTeX 使用原生 MathML。
