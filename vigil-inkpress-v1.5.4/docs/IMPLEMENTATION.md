## 运行边界

- 编辑器使用项目内置 CodeMirror 5，文本内容仍是单一 Markdown 字符串。
- KaTeX 使用本地 MathML 输出，不打包系统字体与外部下载字体文件。
- 自选图片使用 IndexedDB Blob 而非 localStorage，个人数据与偏好分离。
- 备份导出只包含正式手记，不打包个人背景照片和草稿。
- 旧版 v2.8.2 的真实加密导出格式、浏览器私密入口与历史 schema 需要源码和样本，不能凭更新日志推断兼容。

参见 `EDITOR-1.4.2.md`、`LIQUID-GLASS-1.5.md`、`GIT-CRYPT-1.5.md`、`PRODUCT-STRATEGY-1.5.md`、`QA-1.5.md`。

## v1.5.1 编辑器专项结果

实时模式已从「活动行只显示源码」升级为活动行**标记与文本排版同时存在**（部分语法保留源码以便安全编辑），并修复阅读模式外层编辑器占位及段落换行错误；增加活动块预览、动态大纲和撤销/重做操作。当前不是 Obsidian 所有插件的逐 token 完整克隆。

外观预设替换为四种自带背景加用户图片/纯色，旧 `plum`、`bamboo`、`waves` 三种值可迁移。自有字体、KaTeX、GitHub 与 git-crypt 相关存储和文件格式未变。新设计/测试详情见 `EDITOR-1.5.1.md`、`APPEARANCE-1.5.1.md` 和 `QA-1.5.1.md`。

## v1.5.3 · 设置与主题补充

- 四页签设置中心：外观/排版/交互/数据，不再把页签本身做厚重卡片。
- 主题色动态覆盖侧栏、按钮、激活导航、浮层玻璃和焦点；侧栏可主动固定经典墨绿。
- 真实 `backdrop-filter` 毛玻璃侧栏及可调整浓度；减少透明度时自动回退。
- 主题统一下拉选择器，保持原生 `<select>` 的状态来源；键盘和屏幕阅读器语义已补齐。
- 用户可选择轻盈回弹、克制动效或关闭动效；底层手记 Schema 和 GitHub/git-crypt 协议均未改动。

完整说明见 `PREFERENCES-1.5.3.md` 和 `QA-1.5.3.md`。
