## 新增：GitHub 仓库工作区

不属于原 `MVP.md`，属于本轮新增需求：

- 以现有仓库 URL + 分支 + 子目录连接 GitHub。
- 无令牌情况下可浏览公开仓库中的目录和 Markdown 文件。
- 使用只保存在浏览器内存中的 fine-grained PAT 读取私有仓库、修改或新建 Markdown 文件。
- 通过 Contents API 的 `sha` 条件更新避免静默覆盖远端并发修改。
- UTF-8 中文及 emoji 内容使用 Base64 编码进行 API 交换。
- 仓库与本地手记是**相互独立的数据来源**，不是自动双向同步。
- 未提供 GitHub 账号网页登录（OAuth）：需要可信后端才能安全管理 OAuth 登录与令牌交换。
- GitHub 远端连接/提交依赖网络与授权；此交付版本只通过模拟 API 测试了流程，未实际操作你的账户仓库。

## 视觉整理

- 去掉大量无意义英文装饰标签、数字编号、重复说明。
- 以清晰的主导航、页面标题、主要操作、卡片内容为层级。
- 用 12～25px 圆角替代原先的硬边框和直角纸页。
- 保留米白、深墨、朱砂点缀与中式宋体，视觉更轻、更统一。
- 保留你此前提供的 `titlefont.ttf`、`textfont.ttf` 加载路径，不重复分发字体文件。
