# v1.4 参考截图 UI 落地说明

## 映射规则

| 截图区域 | 项目中可维护的实现 |
| --- | --- |
| 墨绿侧边栏 + 朱砂印 | `index.html` 的真实导航和 `inkpress-reference.css` |
| 顶栏山水淡影 | `assets/motif-header-mountain.png`，真实日期由浏览器显示 |
| 主标语与两个按钮 | `src/ui/views/home.js` 中动态生成的可点击元素 |
| 复古打字机、铜灯、梅花与纸张插画 | `assets/typewriter-still-life.webp`，只裁取用户上传的截图插画区域，不包含网页导航/文字区 |
| 山水/梅枝/海波统计卡 | `home.js` 真实统计值 + `assets/motif-*.png` 装饰 |
| 今日节令、续写手记 | `home.js` 依现有节令/草稿/最近手记数据生成，点击进入真实页面 |
| 最近手记 | `entriesCards()`，手记列表可收藏/检索/继续阅读 |

## 为什么不直接把整张截图当作首页

用户要求的是**可运行网站项目**，不是截图或一张只有热区的背景图。因此整个首页的排版、交互、导航、统计以及文字均由 HTML、CSS 和 JavaScript 渲染，静物画只用于装饰。

打字机纸张上截图自带的 `w1` 和日期是画面内插字，不关联实际笔记数据。用户的真实笔记标题和日期以界面列表、阅读器及数据文件为准。若要完全动态替换插画中纸张字样，后续可以把纸张单独拆成一个 DOM 图层。

## 视觉规范

- 深墨绿 `#20342c`、纸本米杏 `#efe4d2`、朱砂 `#a83f2a`、键盘绿 `#29483d`，并保留老式黄铜线条。
- 真实控件仍使用 8～12px 小圆角、控制影深与细框线，不使用浮夸的大圆角/大渐变。
- 以纸张内容、功能标题、按钮为主要阅读层级；插画不截获鼠标事件。
- 在 1672px、1440px、810px、390px、320px 尺寸检查正文与导航是否横向溢出。

## 素材与字体边界

- 插画资源来自用户在当前会话提供的参考图片，属于用户指定的视觉来源；部署时需要用户确认自己有使用权。
- 原有 `titlefont.ttf` 与 `textfont.ttf` 的 `@font-face` 路径保持不变。交付的源码 ZIP 不直接再分发字体文件；用户可以从自己的原项目复制或运行本地字体打包脚本。

## 保留的功能

v1.3 的 Markdown 实时预览、标签/心情/收藏、日历和节气风物、GitHub Markdown 编辑、草稿自动保存、五份本地备份和 JSON 导入导出均在。
