# 不眠手记 · 使用指南

> 适用版本 1.7.8。本文按功能介绍当前应用的用法。历次改动见 `CHANGELOG.md`。

不眠手记（VIGIL Inkpress）是一个本地优先的中文手记应用：正式手记、草稿与备份保存在当前浏览器中；只有你主动连接 GitHub 时，才会访问对应仓库。

## 1. 启动与界面总览

需要 Node.js 18+：

```bash
npm run dev
```

然后访问 `http://127.0.0.1:5173/`。口令加密备份、git-crypt 与剪贴板需要 `localhost` 或 HTTPS 安全环境，不要直接用 `file://` 打开项目。

左侧栏可进入首页、全部手记、日历与风物、线索与行动和 GitHub 仓库。点击右下角的设置按钮可在当前页面上方打开设置。

- 桌面端点击侧栏边缘的折叠按钮，可收成仅显示图标的窄栏；每个图标都有悬停提示，也能用 Tab 键聚焦。
- 平板和手机上侧栏变为顶部栏，右上角菜单按钮展开完整导航，选中后自动收起，`Esc` 也可收起。手机底部另有首页、手记、线索、日历的快捷导航。
- 顶栏提供检索（命令面板）、当前日期和日间/夜间主题切换（窄屏时额外显示设置中心入口）。

**标签页**：「全部手记」「日历与风物」「设置」三处的标签页样式相同：无背景高亮，选中项下方有一条主题色下划线，切换时下划线滑到新标签。「全部手记」「日历与风物」和「设置」的标签获得焦点后，可用 `←` `→` 切换，`Home` / `End` 跳到首尾。

**纸面与玻璃**：顶栏、侧栏、卡片、筛选栏、工具栏与弹层采用折光毛玻璃材质；阅读稿纸、写作稿纸与节令短笺采用温润哑光棉纸与叠页层次。透明程度跟随「设置 → 外观 → 纸面透光」；系统开启「减少透明度」或浏览器不支持背景模糊时，自动改为不透明实色。

## 2. 首页

- **主视觉**：复古打字机静物（可在设置中换成自己的照片），以及「写下今天」「翻阅手记」两个按钮。
- **写作统计**：手记篇数、本月记录篇数、已存文字总数。
- **今日节气**：显示当天节气与节令短句，点击进入「日历与风物」。
- **继续卡片**：有未完成草稿时显示「继续写」；没有草稿时显示最近一篇手记；文库为空时显示「开启第一张纸」。
- **最近手记**：最新三篇手记卡片，右侧「全部手记」进入列表。

## 3. 全部手记

页面顶部有两个同级文库标签：**本地手记**（标签上显示篇数）和 **GitHub 仓库**（显示已连接的 `所有者/仓库`，未连接时显示「尚未连接」）。两个文库互不覆盖：GitHub 文件不会被复制进本地文库，本地手记也不会被推送到仓库。

### 3.1 本地文库：搜索与筛选

- **搜索框**：匹配标题、正文和标签，结果数实时更新。在本页按 `/` 可以直接聚焦搜索框（正在输入框或编辑器中打字时，`/` 照常输入）。
- **快速筛选**（可以组合使用）：
  - **全部**：清空所有条件；
  - **收藏**：只看已收藏的手记；
  - **最近 7 天**：今天及之前六天，不含未来日期；
  - **有待办**：正文含未完成任务（`- [ ]`、`* [ ]`、`1. [ ]` 等）的手记，代码块中的示例不算；
  - **最新优先 / 最早优先**：切换日期排序。
- **标签**：下方列出常用标签（最多 24 个），点击按标签筛选，「全部标签」取消。
- **日期 / 月份**：从日历跳转过来时会显示一个带 × 的日期条件，点击即可移除。
- **清除条件**：有任一条件时出现，一键重置搜索与筛选，不改动任何手记。
- **导出当前结果**：把当前命中的手记下载为 `vigil-selection-YYYY-MM-DD.json`（格式与普通 JSON 导出一致，可再导入）。它不删除、不移动原手记，也不是加密文件；结果为空或文库处于只读保护时按钮不可用。
- **编年目录与导读**：本地列表按年月分组显示四时月令横眉与当月篇数；首篇手记在桌面端跨两列呈现「卷首」舒朗导读，所有手记摘要统一使用清晰易读的正文字体。
- 没有结果时显示「没有找到相关手记」，并不表示手记丢失。

### 3.2 GitHub 文库

**连接仓库**：未连接时，此页提供「连接 GitHub 仓库」入口，跳到侧栏的「GitHub 仓库」页：

- 填写仓库地址（`https://github.com/用户名/仓库名`）、分支（可留空，使用默认分支）、笔记文件夹（可留空）。
- 公开仓库无需令牌即可匿名只读。私有仓库或需要提交修改时，填写 Fine-grained Token，至少授予目标仓库 **Contents: Read and write** 权限。
- 令牌只存在于当前页面会话的内存中，不写入本地存储或备份；刷新页面后需要重新验证。仓库地址会被记住。
- 「本地网络与代理」可指定 HTTP / SOCKS5 代理端口（如 Clash 的 `127.0.0.1:7897`），仅对自带 Node 服务生效；部署到服务器且开启代理锁时不可修改。「测试 GitHub 网络」「浏览器链路检查」用于排查连接问题，均不使用令牌。

连接成功后会自动回到「全部手记 → GitHub 仓库」：

- 顶部显示仓库、分支与当前目录，提供「刷新」和「仓库设置」。
- 点击文件夹逐层进入，「返回上级」回退；只能在你设置的笔记文件夹范围内浏览。
- 只列出 Markdown 文件；搜索框只在**当前目录**内按文件名和路径筛选。
- 本机存有未提交草稿的文件会标注「本机有草稿」。
- **新建仓库手记**：先填写仓库内路径（须以 `.md` 或 `.markdown` 结尾，并位于笔记文件夹内），再点「开始写作」进入完整编辑器。只读连接下此按钮不可用。

## 4. 阅读页

本地手记与 GitHub 手记使用同一张阅读稿纸。

**本地手记**：

- 顶部有「返回手记」「收藏 / 已收藏」「编辑」与删除按钮（删除前需确认，并会自动先做一份备份）。
- 稿纸显示日期、心情、标题、标签、正文和字数。正文完整渲染 Markdown、KaTeX 公式、表格、任务列表、Callout 等（阅读页里的任务框只读，勾选请在编辑器或「线索与行动」中进行）。
- `[[手记标题]]` 是站内链接：点击跳到同名手记；找不到时询问是否新建一篇同名手记。
- 底部有「上一篇 / 下一篇」；若有其他手记引用了本篇，会在「回响 · 引用了这篇手记」中列出。

**GitHub 手记**：

- 标题取自文件名，下方显示仓库路径；顶部有「返回 GitHub 手记」「刷新」「编辑手记」。
- 命中 git-crypt 规则的文件会标注 `git-crypt`；未解锁时需点击「导入密钥」，密钥只保留在本次页面内存中。
- 页脚提示当前是「可编辑并提交到 GitHub」还是「匿名只读」。

## 5. 编辑器

新建、编辑本地手记，以及编辑或新建 GitHub 手记，都使用同一个编辑器。Markdown 原文是唯一的数据，编辑器只负责显示，保存时不会写入 HTML。

### 5.1 页面结构

自上而下依次是：

1. **顶部条**：「← 手记」返回；文稿类型（新手记 / 正在修改 / GitHub 仓库）；草稿状态；主按钮「保存手记」（GitHub 文件为「提交 GitHub」）。
2. **标题**：本地手记可自由命名。GitHub 文件的标题由仓库路径决定、不可在此修改；正文里的 Markdown 标题可以随意改，但不会重命名远端文件。
3. **日期与标签**：标题下方的折叠区（展开后可设置日期、心情、逗号分隔的标签；收起时显示摘要）。GitHub 文件不显示日期与标签。
4. **工具栏**与**模式切换**。
5. **正文稿纸**，底部显示字数与当前模式提示。标题、日期、工具栏固定，滚动时只有正文移动；连续输入正文时周边栏位会柔和退隐，移动鼠标或点击控件即恢复。
6. **稿纸右缘**：与标题同高的竖排书口签上为「大纲」、下为「专注」。
7. **写作窗口外左下角**：编辑 GitHub 文件时，显示「文件名由仓库路径决定……」的提示。

### 5.2 实时 / 阅读 / 源码三态

工具栏右侧的分段按钮在三种模式间切换，切换不会丢失撤销历史或选区，应用会记住你上次使用的模式。

| 模式 | 表现 |
| --- | --- |
| **实时** | 边写边排版。光标所在行保留 Markdown 记号（如 `##`、`**`），同时已显示标题字号、加粗等效果；离开该行后隐藏记号。行内公式在源码旁即时显示，离开后替换为公式。块级公式、表格、代码块在编辑时保留原文，离开整块后显示渲染结果。任务框可直接点击勾选，会改写原文中的 `[ ]` / `[x]`。 |
| **阅读** | 在同一张稿纸上显示完整的只读排版，与阅读页一致。 |
| **源码** | 显示全部 Markdown 原文并带语法高亮，不隐藏任何记号。 |

普通换行会合并为同一段落；需要硬换行时在行尾加两个空格或反斜杠。实时模式接近 Obsidian 的 Live Preview，但不是逐项复刻，复杂嵌套语法可能以源码样式显示。

### 5.3 工具栏

- 常用：**加粗**、**斜体**、**插入链接**。
- **标题** 菜单：一级至六级标题。
- **列表** 菜单：项目符号、编号列表、待办清单。
- **插入** 菜单：引用、行内代码、代码块、行内公式、独立公式、表格、分隔线、删除线。
- **撤销**、**重做**。
- 对同一段文字再次应用相同格式会取消该格式；无需重新选中两侧的 Markdown 标记。标题、引用、列表同样可以取消。代码块与独立公式选中整块后再次操作会解除包装；表格与分隔线仍是插入操作。

### 5.4 专注与大纲

- **专注**（沉浸书写）：隐藏侧栏与顶栏，稿纸按设置中的工作区宽度展开，并收紧四周留白，扩大正文空间；标题与工具栏仍固定，只有正文滚动。再次点击「退出沉浸」或按 `Esc` 返回。快捷键 `Ctrl/⌘ + Shift + F`。
- 进入、退出专注模式时书写台平滑展开与收回，可在过渡中再次切换；「减少动态效果」或关闭动效时直接切换。
- **大纲**：根据正文标题自动生成并随输入更新，点击条目跳到对应位置。
  - 桌面端：大纲收起时是稿纸右缘的小标签，点击后向左展开为与稿纸等高的纵向窗口，稿纸略微让出宽度；窗口展开时文字位置不动。收起后不占位，也不会被 Tab 键聚焦。
  - 平板与手机（≤900px）：大纲浮在稿纸右侧，不挤压正文；点击关闭按钮或按 `Esc` 收起。
  - `Esc` 也可收起大纲。

### 5.5 查找与替换

`Ctrl/⌘ + F` 打开查找条，`Ctrl/⌘ + H` 打开并聚焦替换。支持上一个 / 下一个、替换、全部替换；`Esc` 关闭。只作用于当前文稿。

### 5.6 编辑器快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl/⌘ + S` | 保存手记 / 提交 GitHub |
| `Ctrl/⌘ + B` / `Ctrl/⌘ + I` | 加粗 / 斜体 |
| `Ctrl/⌘ + Z` / `Ctrl/⌘ + Y` | 撤销 / 重做 |
| `Ctrl/⌘ + E` | 在实时与阅读模式间切换 |
| `Ctrl/⌘ + F` / `Ctrl/⌘ + H` | 查找 / 替换 |
| `Ctrl/⌘ + Shift + F` | 专注（沉浸书写） |
| `Esc` | 依次关闭：查找条 → 格式菜单 → 大纲 → 专注 |

### 5.7 KaTeX 数学公式

使用项目内置的 KaTeX（离线，无需 CDN），以浏览器原生 MathML 输出。

- 行内：`$E=mc^2$` 或 `\(E=mc^2\)`
- 块级：单独成行的 `$$` 包住多行公式，或 `\[ … \]`，也支持单行 `$$…$$`

```markdown
勾股定理 $a^2+b^2=c^2$。

$$
\sum_{k=1}^{n}k=\frac{n(n+1)}{2}
$$
```

公式以安全模式渲染（不信任输入中的 HTML 或危险命令）。排版细节与 KaTeX 的 HTML+字体模式略有差异，推荐使用现代 Chrome / Firefox / Safari。

### 5.8 标题、引用与 Obsidian Callout

支持一至六级标题，以及由连续 `>` 行组成的引用；`> >` 为嵌套引用。在引用首行写 `[!类型] 可选标题` 即成为 Callout：

```markdown
> [!note] 一般提示
> 内容

> [!tip]+ 可收起，默认展开
> 内容

> [!question]- 默认折叠
> 点击标题才显示内容
> > [!note] 内层提示
> > Callout 可以嵌套
```

### 5.9 受限的字体 HTML

为排版需要，正文中允许少量 HTML 标签：`span`、`u`、`s`、`small`、`mark` 与块级 `div`。

```markdown
<span class="font-kai" style="font-family: KaiTi; font-size: 18px">一字一句</span>
<div class="font-song" style="text-align: center">纸上有山川</div>
```

- 允许的 `style` 属性仅限字体、字号、字重、斜体、文字装饰、颜色、字距、行高和对齐，取值也有范围限制。
- 内置字体类：`font-kai`、`font-song`、`font-sans`、`font-typed`、`font-accent`；其他类名会保留，但需在项目 CSS 中自行定义才有效果。
- 脚本、事件属性（`on*`）、`iframe`、`url(...)` 和外部样式表一律不会执行。这不是完整的 Obsidian CSS snippets 引擎。

### 5.10 保存、草稿与离开

- 输入时自动暂存草稿，顶部显示草稿状态；切到后台或关闭页面时也会保存草稿。
- 本地手记：点击「保存手记」或 `Ctrl/⌘ + S` 写入正式文库。重新打开有草稿的手记时，会询问是否恢复草稿。
- GitHub 手记：草稿只存本机，**只有点击「提交 GitHub」才写入远端**。提交时携带原文件的 SHA，远端已被他人修改时会拒绝覆盖；每次提交前重新检查仓库 `.gitattributes`，命中 git-crypt 规则的文件必须先导入匹配密钥并以加密形式提交，规则无法确认时拒绝明文写入。提交失败时，本机草稿保留，不会自动重试。
- 草稿保存失败、或 GitHub 修改尚未提交时离开编辑器，会弹出确认。

## 6. 日历与风物

一个页面、两个标签：**日历归档** 与 **节气风物**，共享同一个所选日期。标签栏旁显示所选日期及其节气与当前候；右上角「回到今天」同时重置两个视图。在日历选中某天后切到节气，看到的就是同一天的节令；反之亦然。

### 6.1 日历归档

- 月历：用箭头翻月，「今天」回到本月。朱砂标记为节气日，墨点表示那天写过手记。
- 点击某天，右侧「所选日期」卡片显示公历、农历、节气、月相、节令短句，以及当天的手记（点击即可阅读）。
  - 「查看节令」：切到节气风物并定位到该日；
  - 「筛选手记」：跳到「全部手记」并按该日筛选。
- **月份归档**：列出每个有手记的月份及篇数，点击跳到该月。
- **往年今日**：若往年同一天写过手记，会在此列出。

### 6.2 节气风物

- **节气盘**：外环为 24 节气。
  - 鼠标或触摸在外环拖动可逐日漫游（中心区域不参与拖动）；
  - 滚轮向下看后一天、向上看前一天；
  - 键盘聚焦节气盘后：`←` `→` 逐日，`PageUp` / `PageDown` 跨节气，`Home` / `Esc` 回到今天；
  - 直接点击某个节气，跳到当年该节气当日；
  - 下方「前一日 / 后一日」按钮逐日切换。
- **当前节气卡**：节气名、季节、起始日期、下一个节气、节令说明、农历与月相（示意）。
- **节气三候**：显示该节气的初候、二候、三候，并高亮所选日期所在的一候（每候约五日）。
- **节令短笺**：为本应用创作的短句，并非古诗引文。

**精度说明**：节气由太阳视黄经近似计算，按北京时间（UTC+8）判定日期，支持 1901–2099 年；与官方历表可能相差数分钟。三候是传统物候文化表达，不代表当地实际物候；月相按平均朔望月估算，仅作示意。农历依赖浏览器的中文历法支持，不支持时会降级显示。系统要求减少动态效果时，节气盘不播放转动过渡。

## 7. 线索与行动

所有统计、任务与关联都在本机从本地手记计算，不调用云端服务，也不上传正文。

- **概览**：近七日记录数、连续写作天数、未完成事项数、手记之间的关联数。
- **行动清单**：自动收集所有手记中的 `- [ ]` 任务。点击圆框即可勾选或取消，会同步修改原文（修改前先做一份安全备份）；右侧箭头打开原手记。任务中写有日期（如 `2026-12-01`，也可写成 `📅 2026-12-01`、`due:2026-12-01`、`截止:2026-12-01`）时显示截止日，过期会标注「已逾期」，并按截止日排序。
- **一周回顾**：根据最近的手记生成一个回顾提示，点击「写下这段回顾」开始新手记。
- **关联手记**：列出通过 `[[另一篇手记标题]]` 建立的关联，点击打开目标手记；若有链接找不到目标，会提示未解析的数量。
- **常写主题**：最常用的标签及次数，点击按该标签筛选手记。

## 8. 设置中心

设置分为四个标签：**外观、排版、数据、关于**。所有设置即时保存在当前设备，不修改手记。「恢复默认设置」会恢复外观、材质、动效与正文排版，不删除手记或已上传的图片。

桌面点击左侧栏右下角的设置按钮打开面板，窄屏入口在顶栏。也可通过快速检索打开「设置中心」或「设置 · 关于」。点击关闭按钮、点击面板外或按 Esc 即可返回当前页面。

标题、操作按钮与分类标签固定在面板上方。设置项在内容区滚动，切换分类后从该区顶部开始。

### 8.1 外观

按五组排列：

- **颜色与明暗**：暖纸日间 / 深墨夜间；朱砂、松绿、黛蓝、铜金、梅紫、墨青与自定义主题色。
- **背景**：晴岚、薄雾、素岸、月汐、我的背景、纯色；可上传图片并调整背景强度（0–85%）。图片只保存在当前设备；原文件不超过 12MB，长边缩到 1920px 内，转为 WebP 后不超过 3MB。
- **纸面与玻璃**：纸面透光（50–100%）、侧栏配色、着色浓度（55–96%）、模糊程度（0–36px）、悬浮控件浓度（28–92%），以及纸张纤维开关。
- **首页静物**：经典打字机或自己的照片；与背景共用相同的图片选项、上传和恢复操作样式。
- **光影与动效**：动效强度（轻盈回弹 / 更克制 / 关闭）；Spectral Drape 点阵帷幕及其光点强度；全局 3D 浮动及其幅度（0–100%，默认 50% 保持原角度）。两个特效相邻但独立开关，关闭后相应强度滑杆禁用。

浮动只影响纸面、卡片和浮层，侧栏与顶栏保持静止；触屏自动保持平面，拖选时不更新角度。更克制模式减小幅度，关闭动效或系统开启「减少动态效果」时浮动停用、帷幕保持静态。页面隐藏时暂停特效。

### 8.2 排版

- **字体风格**：原版文房、宋体阅读、现代无衬线、楷体手札，字体缺失时回退到系统字体。
- **正文大小**（13–22px）、**行间距**（1.45–2.5）、**版心宽度**（860–1740px）。同时影响写作、阅读和手记卡片。

### 8.3 数据

见 [第 10 节](#10-本地数据与备份)。

### 8.4 关于

- 显示版本号、本机正式手记 / 草稿 / 备份数量，以及数据隐私说明和文档链接。
- **本地环境检查**：只在你点击「开始检查」时运行，检查本地存储、图片存储（IndexedDB）、Web Crypto 与安全环境、Markdown 编辑器、KaTeX、文库是否处于只读保护、GitHub 工作区本次是否已连接（不是远端连接质量检测）。不联网，不读取正文。
- **复制诊断摘要**：只复制检查结果和数量，不包含手记正文、标题、仓库信息、令牌、密钥或背景图片。

## 10. 本地数据与备份

### 10.1 数据存在哪里

| 存储位置 | 内容 |
| --- | --- |
| `vigil-mvp-data-v1` | 正式本地手记（Schema v1 JSON） |
| `vigil-mvp-drafts-v1` | 自动草稿，含 GitHub 文件草稿（以 `github:<哈希>` 区分，哈希由仓库、分支、路径生成，不含令牌） |
| `vigil-mvp-backups-v1` | 本地备份快照，最多 5 份 |
| `vigil-appearance-v142` | 外观与排版设置 |
| `vigil-theme-v1` | 日间 / 夜间主题 |
| `vigil-editor-mode-v142` | 上次使用的编辑模式 |
| `vigil-sidebar-collapsed-v1` / `vigil-mobile-nav-open-v1` | 桌面侧栏折叠、手机菜单展开状态 |
| `vigil-github-repository-v1` | 仓库地址、分支、文件夹（**不含令牌**） |
| IndexedDB `vigil-appearance-image-v142` | 自定义背景与首页静物图片 |

GitHub 令牌和 git-crypt 密钥只存在页面内存中，任何本地存储和备份中都没有。

### 10.2 「设置 → 数据」

- 顶部显示本地数据大约占用的空间（背景图片单独存放，不计入）和手记 / 草稿 / 备份数量。
- **导出 JSON**：把全部正式手记保存为文件。不含草稿、背景图片、外观设置或 GitHub 文件。
- **导入手记**：选择 JSON 文件导入（不超过 8MB），确认后**替换**当前文库；导入前会自动备份当前文库。
- **口令加密备份**：「加密导出」使用 AES-256-GCM 加密导出文件，口令只用于本次操作，请务必牢记；「加密导入」用于恢复此类文件。
- **git-crypt 文件工坊**：导入仓库的 git-crypt export-key 后，可在本机加密或解密 Markdown 文件，密钥不上传。git-crypt 与口令加密 JSON 是两种不同格式，不能互换。
- **本地备份**：最多保留最近 5 份。可「立即备份」、恢复（恢复前也会先备份当前文库）或删除某份备份。删除手记、导入、恢复、勾选任务等操作会自动创建备份。
- **未完草稿**：列出全部草稿，可「继续」或舍弃。
- 文库中有示例手记时，可「清除演示」，只删除示例内容。

### 10.3 重要提醒

- 草稿、备份与正式手记都在同一个浏览器中。**清除站点数据会把它们一起删掉**。需要长期保存时，请定期导出 JSON 或加密备份并妥善保管。
- 本地存储读取异常时，文库会进入只读保护，导出、导入等按钮暂不可用，并提示前往「设置 → 数据」查看。

## 11. 已知边界

- 没有自动跨设备同步，也没有本地文库与 GitHub 之间的双向同步；不支持远端文件重命名或批量同步。
- GitHub 冲突不会自动合并：远端有新提交时请先刷新，确认差异后再编辑。
- git-crypt 需要你合法导出的仓库密钥。
- 不是完整的 Obsidian：没有插件系统，不执行任意 CSS 或脚本，复杂嵌套 Markdown 可能以源码样式显示。
- 不支持原 v2.8.2 的数据迁移、存储 Schema 或历史加密文件；这些兼容能力属于明确的非目标，不是待验证功能。
