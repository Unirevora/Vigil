# 不眠手记 · 重构版更新日志

## v1.7.5 · 浮光

**工具栏反馈更柔和，菜单恢复半透明玻璃；全局 3D 浮动可即时开关，点阵帷幕减少重复绘制。**

### 编辑器

- 格式按钮的位移、按压与颜色使用连贯过渡，去掉悬停大幅放大、按压骤缩及只过渡颜色的旧规则；菜单用轻微位移与淡入展开。
- 标题、列表、插入菜单采用独立的半透明底色（日间 72%、夜间 78%），保留实际背景模糊；减少透明度时仍回退为实色。
- 阅读模式打开长文时不再由页面视图和编辑器挂载各解析一次整篇 Markdown；统一由编辑器渲染并沿用原文缓存，减少重复解析与 DOM 写入。
- 实时模式的滚动锚点改用窗口坐标，保持重绘前后实际可见行的位置；修复 CodeMirror 虚拟视口产生偏移后，长文中段与底部装饰重建时自动错位的问题。

### 全局浮动

- 新增统一的 `ui/floating.js` 与 `styles/floating.css`，纸面、卡片、工具区域与弹层随鼠标轻微改变角度；侧栏与顶栏保持静止，嵌套内容跟随所属面板，不重复倾斜。
- 「设置 → 外观」在 Spectral Drape 旁加入「全局 3D 浮动」开关与 0–100% 幅度滑杆，默认开启、幅度 50%（保持原来的角度），即改即生效并保存在既有外观偏好中；关闭时禁用幅度控件。减少动效、关闭动效、触屏或后台页面会停用；更克制模式降低角度。
- 共用一次指针监听与按需帧更新，不建立逐卡片监听或持续动画循环；保留原有悬停、进场、大纲及专注切换动画。
- 修复长手记、长列表开启浮动时的极端拉伸：透视距离随容器尺寸调整，超长面板按尺寸降低实际倾角，限制深度变化。由统一 ResizeObserver 在布局变化后重测，鼠标移动时不读取布局；短卡片、幅度开关和编辑器交互保持可用。

### 点阵帷幕

- 缓存光点与光晕贴图、预计算网格参数，替代每帧创建径向渐变；画布不再按高 DPR 放大，最多约 160 万像素。
- 绘制间隙休眠、按绘制负载调节帧率；相同设置不重启动画。关闭后释放画布像素，隐藏页面暂停，关闭动效或减少动效时只画静态帧。
- 光点强度与说明直接排列在设置面板中，去掉单独的背景、圆角和桌面 / 手机内边距，与其他设置项保持一致。

### 清理与测试

- 设置页标题、说明、恢复按钮与分类标签固定在上方，只有下方内容面板滚动；随窗口尺寸和移动导航高度变化重新适配，不再滚动整页。
- 修复数据与备份中的导入、导出卡片：恢复统一边框、圆角与内边距，桌面两列等高、按钮靠底对齐，窄屏纵向排列；清理旧的无边框平铺规则和通用表面类冲突。
- 设置页按「外观 / 排版 / 数据 / 关于」四类整理；材质、侧栏、纸纹与动效统一归入外观，浮动与帷幕相邻，正文排版单独成页。删除旧「交互」入口，标签渲染与键盘导航共用一份分类清单。
- 设置开关、滑杆、下拉行与图片选项各用一套组件和样式；背景与首页静物统一选中标记，帷幕和浮动统一强度布局与禁用状态。上传入口改为键盘可操作的按钮，恢复默认的提示与实际范围一致。
- 清理旧 `.setting-*` 控件、专属帷幕样式与徽标、玻璃演示块、卡片/胶囊标签规则、重复标题与夜间覆盖；设置模块直接维护最终样式，不再用后置补丁叠加。
- 删除旧逐点渐变绘制、密集逐帧轮询、重复设置重启与常驻 `will-change`；移除工具栏生硬的缩放和覆盖规则，以及「交互」中的旧浮动入口，不保留重复设置。
- 补充外观保存失败保护、浮动幅度与帷幕像素预算、静态和停用时调度清理的测试；版本号统一更新到 1.7.5「浮光」。
- `main.js` 保留启动、路由、草稿、编辑器与生命周期，GitHub 和数据运维分别由 `ui/github-controller.js`、`ui/data-controller.js` 持有；全部 `data-action` 经合并注册表与 `action-dispatcher.js` 分发，动作名称、共用筛选复位和保存顺序不变。补充静态/运行时 action 覆盖与控制器所有权测试。
- 同步产品、架构、QA、用户指南与字体文档，修正样式模块化状态、字体路径、当前版本说明及真实浏览器未验证边界。
- 原 v2.8.2 的数据迁移、存储 Schema 与加密格式兼容调整为明确非目标，不再作为发布门槛或后续方向；早期网页原型键的一次性复制保持不变。
- 补充阅读模式单次渲染与虚拟视口锚点回归测试；使用 500 节、2999 行长文在本机 Edge 验证中部、80% 与底部滚动重绘，可见行按高度变化精确补偿，阅读正文完整且无 JavaScript 错误。

## v1.7.4 · 定框

**编辑器固定在视口内，只有正文滚动；大纲与专注收在稿纸右缘，GitHub 文件提示移到写作窗口外。**

### 编辑器

- 标题、工具栏固定不动，实时 / 阅读 / 源码三种模式都只滚动正文；整页不再滚动。编辑器高度随窗口大小与专注模式自动计算（`fitEditorFrame`）。
- 大纲与稿纸同排：收起时是稿纸右缘、与标题同高的小标签，展开为与稿纸等高的纵向窗口，稿纸让出约 272px 并有过渡动画；展开时文字位置不随窗口移动。窄屏（≤900px）改为浮在稿纸右侧，不挤正文。
- 「专注」按钮放在大纲标签正下方（展开后在大纲标题栏中），不再单独占一行。
- 专注模式沿用设置中的工作区宽度，稿纸不再受额外宽度上限限制；缩小四周留白，让桌面、平板与手机都有更宽、更高的正文空间，底部保留安全区。
- 进入与退出专注模式时，书写台的位置、宽高平滑过渡；中途再次切换从当前位置反向衔接，结束后重新测量编辑器，不重建正文。服从「更克制 / 关闭」设置与系统减少动态效果偏好。
- 重复点击加粗、斜体、删除线、行内代码、公式与链接时，识别选区周围已有的标记并取消格式，不再嵌套；标题、引用与各类列表按样式取消，混合选区统一应用。选中的代码块与公式块重复操作也会解除包装。
- 标题、列表、插入菜单改用较厚的玻璃底色；工具栏玻璃移至独立底层，让菜单能模糊下方正文。手机端以工具栏定位菜单，避免标题菜单超出屏幕；夜间主题与减少透明度的实色回退保持一致。
- 「专注」与「日期与标签」原先同占一行：专注挪走后，「日期与标签」仍在标题下方的原位，只是不再与按钮挤在一行。
- GitHub 文件的提示「文件名由仓库路径决定；正文中的 Markdown 标题可以自由编辑，提交时会校验 SHA 与加密规则。」移到写作窗口外的左下角，不再占用稿纸里的一行。
- 实时模式支持分割线（`---`、`***`、`___`）：光标离开该行后显示为横线，回到该行恢复源码。

### 清理

- 删除专注模式旧的 1180px 工作区上限、大幅左右留白与 48px 高度回退间距，直接修订原样式，不叠加遗留覆盖规则。
- 删除工具栏与菜单重复覆盖的旧模糊、背景及夜间规则；格式包装统一由纯函数处理，移除编辑器里重复拼接代码块与公式块的逻辑。
- 删除编辑区、阅读区所有旧的 `min-height` / `max-height` / `vh` 上限、旧的右侧栏与移动端抽屉、遮罩、顶栏大纲按钮、属性行及专注按钮样式；去掉 CodeMirror 内联的 510px 最小高度与 `editor-manuscript-layout` 容器。
- 删除未被任何页面使用的素材 `assets/bamboo-gold.svg`、`assets/paper-fibers.webp`。

## v1.7.2 · 流光

**标签切换有了动画，毛玻璃延伸到阅读与写作稿纸，样式表从版本补丁层整理为功能模块。**

- 标签切换动画：页面切换标签时整块重新渲染，CSS 过渡从来不会触发。现在每组标签共用一条指示条，记住上一次的位置，重新渲染后用 Web Animations 从旧标签滑到新标签；首次出现直接就位，开启「减少动态效果」时不播放动画，窗口尺寸或字体变化时重新测量。
- 阅读页与编辑器稿纸加入毛玻璃（比卡片略厚，便于长文阅读）。玻璃画在稿纸的 `::before` 底层，而不是稿纸本身——`backdrop-filter` 会让平板与手机上 `position:fixed` 的大纲抽屉被困在稿纸内。
- 样式表重构：26 个按版本命名、层层覆盖的补丁文件（`vigil-153.css` … `vigil-171.css`、`polish-152.css`、`editor-refine-151.css` 等）整理为 20 个按功能命名的模块（`tokens`、`base`、`controls`、`dialogs`、`shell`、`home`、`entries`、`reader`、`editor`、`chronicle`、`insights`、`github`、`settings`、`tabs`、`surfaces`、`focus` 等）。
  - 删除 1456 条被同一选择器后续规则覆盖、从未生效的声明，以及 286 条选择器所需类名在代码中已不存在、永远不会匹配的旧规则（欢迎卡、旧编辑器分栏、旧节气轮盘等）。
  - 模块顺序由层叠冲突分析求出：在真实页面上找出所有「只由先后顺序决定胜负」的规则对（1282 对），排出满足全部约束的模块顺序；19 条必须排在所修饰规则之后的规则留在较后的模块中，并附注释说明。
  - 带版本号的命名一并改掉：类名 `settings-153` → `settings-hub`，变量 `--v155-title-size` 等 → `--page-title-size` 等，层名 `@layer vigil-171` → `@layer overrides`。
  - 验证：在 2 种主题 × 3 种宽度 × 17 个页面状态下，逐个比较 28656 个元素与伪元素的全部计算样式，重构前后完全一致。

## v1.7.1 · 一种标签，满窗毛玻璃

**三处标签页统一为一种样式，毛玻璃覆盖到界面卡片；编辑器工具并入属性行，大纲变成与稿纸等高的侧栏。**

- 「全部手记」「日历与风物」「设置」的标签页统一为全部手记的下划线样式：任何状态都**不再有背景高亮**，选中项只显示一条 4px 圆角主题色下划线（原为 2px 直角），切换时下划线从中心弹性展开，悬停时淡淡预示。键盘左右键切换照旧。

### 编辑器

- 「专注」「大纲」按钮移到「日期与标签」同一行的右侧（大纲在专注右边），删除下方单独的工具行，正文上移一行。窄屏只显示图标。
- 「日期与标签」的展开箭头紧跟文字，不再漂在行尾。
- 桌面端大纲由右上角的悬浮小窗改为编辑区右侧的一整列：点击后宽度以弹性动画展开到 288px，高度与编辑区一致；长文滚动时大纲内容始终停留在视野内。收起后不可再被 Tab 键聚焦。平板与手机仍为右侧抽屉。
- 大纲展开或收起的动画结束后，编辑器会重新测量宽度，避免换行错位。

### 部署与网络

- 支持部署在子路径下（如 `https://服务器:8443/vigil/`）：页面、脚本、GitHub 中继地址改用相对路径；CSS 模块仍写 `/assets/...`，由 `build:css` 打包时换算为相对路径，并拒绝引用不存在的文件。
- 由自带 Node 服务提供的页面在任何主机名下都使用同源 GitHub 中继（此前仅限 localhost）；纯静态托管仍直连 GitHub。
- 修复 Safari 在自签证书 HTTPS 下连接仓库报 `FETCH_REJECTED`：同源中继请求改用 `credentials: 'same-origin'`（nginx 丢弃 Cookie），直连 GitHub 仍为 `omit`。
- 修复 Safari 下默认壁纸请求到 `assets/assets/...` 导致背景缺失。
- 新增服务器代理锁 `VIGIL_PROXY_LOCK`：服务器部署时，访客无法把服务器出口改成自己电脑上的 Clash 端口。
- 新增一键部署 `deploy.cmd` / `npm run deploy`：构建、本地与服务器测试、上传、切换版本、更新 systemd 与 nginx、九项健康检查，失败自动回滚。

### 测试

- 新增 `tests/release-171.test.js`（统一标签、毛玻璃范围、编辑器布局、大纲行为、版本一致性）与 `tests/subpath-deploy.test.js`（子路径、CSS 换算、中继识别、代理锁）。

## v1.5.6 · GitHub 请求接口生命周期热修复（版本不变）

- 修正 `GithubClient` 在页面启动时缓存旧 `fetch` 函数，导致浏览器链路检查使用新 `fetch` 通过、仓库连接却继续用旧函数抛三个 TypeError 的不一致行为。
- 默认浏览器连接改用请求时的 `globalThis.fetch`；保留明确注入的自定义 fetch 测试函数。
- 匿名连接失败时按「发送请求／检查响应头／读取 JSON／校验状态」记录安全阶段与错误枚举，不显示仓库地址、Token 或正文。
- 添加能在未修复代码上复现用户三条 TypeError、修复后成功读取元数据与目录的回归测试；Chromium 单独验证同一客户端行为。
- 不更改 Clash 代理设置、匿名/认证读写隔离、PUT 不重试原则、git-crypt 或现有文库 schema。
- 本地外网到私人仓库仍须在用户电脑上最终验证。详见 `docs/GITHUB.md`。

## v1.5.6 · GitHub 浏览器仓库请求参数一致性热修复（版本不变）

- 公开仓库连接的匿名 GET 改为与成功的浏览器链路诊断一致的 `Accept: application/json` 等请求选项。
- 修复主通道中断后备用通道复用已取消 AbortSignal 的风险；每次请求独立超时，读取 JSON 正文的错误也可进入只读后备。
- 加入连接阶段/通道/状态的脱敏错误详情；不能仅依赖探测 200 判断连接成功。
- 保持带 Token 读取、GitHub 提交 PUT 不进行不确定的匿名后备或重试；不改变现有数据结构。
- 新增差异复现测试及安全回归，详见 `docs/GITHUB.md`。

## v1.5.6 · 浏览器仓库链路热修复（版本号不变）

- 修复“Node 命令行五项诊断全通过，浏览器 `fetch('/api/github/repos/...')` 仍抛 TypeError”时无法确定故障环节的问题。
- 为公开匿名 GET 增加备用同源路径 `/api/vigil-bridge/repos/...`；第一次主路径被浏览器阻断后切换备用路径，并在后续目录读取中沿用，不重复触发已知失败请求。
- 备用通道只允许无令牌 GET，拒绝所有 Authorization 和写入；原有路径、主机、查询及正文限制全部保持不变。
- GitHub 页面增加“浏览器链路检查”，分别测试诊断、主同源路径、备用同源路径和浏览器匿名直连；不输出令牌或私人数据。
- `npm run diagnose:github` 新增备用同源路径验证，由原来的五阶段扩展为六阶段。
- 修正三通道全部失败后错误被泛化为 `Error` 的问题，保留各通道的错误名称以便定位。
- 新增对应 Node 回归测试与本地服务器 HTTP 模拟测试，未宣称连接过用户真实 Clash 节点。
